# Сигма-модель: уточнение от 2026-11-23

Черновик для будущей правки текста. В LaTeX пока не переносится.

## Исход взаимодействия

- `sigma = +1` — контакт состоялся успешно;
- `sigma = 0` — отказ;
- `sigma = -1` — контакт состоялся, но неудачно.

## Влияние сигмы на ось

Правило одинаково для эмоций и для реляционных функций `U`, `T`, `A`.

Пусть:

- `x` — текущее значение оси;
- `d` — базовая дельта взаимодействия;
- `alpha = 0.5` (`SIGMA_RATE` в Python и C++).

Тогда:

| sigma | `x >= 0` | `x < 0` |
|---|---|---|
| `+1` | `d * (1 + alpha)` | `d * (1 - alpha)` |
| `-1` | `d * (1 - alpha)` | `d * (1 + alpha)` |
| `0`  | резкая отрицательная реакция | резкая отрицательная реакция |

Для `U/T/A` базовая дельта `d > 0`: и успех, и неудача повышают значение.
Отказ — единственный исход, который понижает `U/T/A`. Для эмоций
`d = 0.15 * s_i * context * (E_j - E_i)`: успех и неудача сближают
эмоциональные профили, отказ — разводит.

Пример при `alpha = 0.5`, `d = +10`:

- `x = +20`: успех `+15`, неудача `+5`;
- `x = -20`: успех `+5`, неудача `+15`.

## Что это меняет в тексте

В `pdf/kursa4.tex` строка 227 говорит: «В случае успеха также повышаются
`U_ij`, `A_ij`, `T_ij`, а при неудаче — понижаются». Это больше не
соответствует модели: неудача тоже повышает `U/T/A`, но медленнее на
положительной полуоси и быстрее на отрицательной. Понижает только отказ.
